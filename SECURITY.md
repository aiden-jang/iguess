# Reporting a security issue

Report suspected vulnerabilities privately from the repository's
[Security tab](https://github.com/aiden-jang/iguess/security), or email
[me@aidenjang.com](mailto:me@aidenjang.com). Include the
behavior, affected route or component, and the smallest reproduction you can share safely.
Keep credentials, private drawings and exploit details out of public issues.

iguess has public, account-free rooms. Room links allow people to join; reconnect credentials
protect an existing seat rather than making the room private. Provider secrets belong in
Worker secrets or ignored local files. Automated tests use mock vision.
