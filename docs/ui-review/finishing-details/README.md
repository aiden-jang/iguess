# Update and shortcut details

Update notices stay on the entry screen, preserve the name draft and wait for an
explicit choice. Later dismisses the notice. Active rooms keep their game controls
without an update prompt. Command/Ctrl hints follow the player's platform.

- [Desktop update](update-desktop.png)
- [Phone update](update-mobile.png)

Browser journeys cover dismissal, entry-to-room navigation, room fit, reconnecting
without losing chat drafts, and the installed shell's network-only API behavior.
Local AI is mocked; no paid provider runs. Physical install menus, native keyboards
and background recovery still need a device check.
