# Reaction stickers and field details

The current reaction choices use bundled vector stickers in the picker and on the
board. Accessible names, captions and network values stay the same; older reactions
remain readable. Guess inputs keep spelling correction off while ordinary room chat
uses normal text-entry behavior. Autofill follows the light/dark palette.

- [Desktop stickers](refinement-reactions-desktop.png)
- [Phone stickers](refinement-reactions-phone.png)

Browser journeys send every reaction through a local room in both engines, check
its matching board artwork and confirm that chat stays reachable. Local AI remains
mocked. Physical keyboards, native autofill and paid-provider output remain outside
this review.
